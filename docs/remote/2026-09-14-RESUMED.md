## Root cause and scoped repair

The independent Go HC test client used a 32-character hexadecimal random ID for DPoP `jti`. The production verifier requires a canonical UUID v4. Its authenticated discovery request therefore returned 401; the test kept polling and mislabeled the failure as an ABA connection timeout. The repair generates proper random UUID v4 values, adds an ordinary unit-level authenticated-discovery regression test, fails immediately on discovery authentication failures, and bounds safe diagnostic logs. It also integrates the already authored canonical private TempDir repair. No production authentication rule is relaxed and no timeout is extended to hide the failure.

The patch is a saved source checkpoint only. The reviewed-candidate workflow must verify it, after which an explicit source commit promotes the exact reviewed tree and removes the temporary patch. Normal CI must rerun on that source commit.
