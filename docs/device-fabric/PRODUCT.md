# 产品范围、体验与首版闭环

- 状态：Draft，2026-09-13。

## 1. 定位

Harness：随时随地把任务交给自己的 Agent，并通过自己授权的设备接收结果、提供输入和执行有限动作。

HC Web/App/小程序、Mosaico 可以都是交互入口，也可以是能力提供者，但能力平等不意味着权限、安全等级或交互完整度相同。ABA 仍是设备连接器的执行侧安全边界，不在普通用户界面引入更多底层缩写。

## 2. 四个用户故事

### U1：桌面实体任务伴侣

用户在 HC 发起任务，选择将进度卡片显示到已配对 Mosaico。可信执行区生成最小摘要并加密给设备。设备可以亮屏、震动、显示状态；详细源码和整个对话不自动同步。点击“详情”在 HC 打开同一 Task，设备只持短期引用。

### U2：实体终端提供输入

用户先在已认证 HC 激活一段短期 Mosaico 交互权限。设备选择预先授权的任务或模板，发送文本/按键意图；后续按键录音经可信语音组件转写。Interaction Adapter 按 Run/控制租约校验，再构造 ACP 请求。未激活或无控制权时只显示“在手机确认”。

### U3：Agent 使用设备能力

Agent 请求在指定设备显示卡片、读取许可状态或拍摄经用户同意的图像。MCP 调用进入本地 Device Bridge，由授权策略、参数约束和设备本地许可共同决定是否执行。设备报告结果，HC 能分清“投递完成”和“操作完成”。

### U4：跨端审批

ACP runtime 产生真实权限请求。可信 Approval Authority 生成一次性审批事务。Mosaico 可显示低风险请求并在已授权的人类交互期限内提交决策；敏感/高风险操作转交更高保证级别 HC。设备不能显示完整安全必需信息时禁止批准，不能以“摘要已显示”代替知情授权。

## 3. 产品对象

`Project → Task → Run → SessionBinding`；Task 保持用户目标，Run 是一次执行尝试，Session 是当前协议连接对象。`Approval`、`Artifact`、`DeviceInvocation` 关联 Run，但生命周期独立。

更换 Runtime 或执行位置产生新 Run。重连不产生新 Run。不支持 session/load 的 Runtime 不能恢复进程内会话；只能显示最后可信状态并由用户选择新的执行尝试。

## 4. HC 界面增量

- 任务详情：任务状态、执行状态和连接状态独立；显示使用了哪个设备、最后可信结果、取消是否确认。
- 我的设备：执行设备、交互终端和传感设备可按标签筛选；展示信任级别、能力实际可用性、绑定、授权范围与撤销。
- 配对：短码/二维码、名称、密钥指纹、所属空间、能力申请与有效期；个人操作不强制跳管理后台。
- 审批收件箱：原动作对象、范围、风险、有效期、决策人以及转到安全终端；不出现 Agent 可点击的自动批准入口。
- 通知偏好：哪些任务发往哪个设备、是否允许屏幕显示摘要/语音播报、勿扰和隐私模式。

## 5. Console 界面增量

设备目录、授权策略、能力合约版本、元数据审计、运行关联、投递诊断、固件发布记录。管理员不自动获得内容解密权。设备状态页面明确区分 Platform 可见的运维值与只能在授权 HC 里解密的业务值。

首版不增加独立 Device Groups、资源池、调度大屏和账单系统。平台已有的组织、RBAC、菜单、审计、任务框架继续复用。

## 6. Mosaico 页面合同

| 页面 | 必需元素 | 安全限制 |
| --- | --- | --- |
| 未绑定/配对 | 一次性码、指纹片段、期限、取消 | 不展示或打印长期凭据 |
| 首页 | 当前空间、任务、网络、静音、锁定状态 | 不显示无权访问的任务摘要 |
| 任务卡 | Task/Run 短标识、阶段、最后更新时间 | 无可信进度数据时不伪造百分比 |
| 交互 | 预置操作、录音指示、取消 | 无有效 Actor Lease 不接受用户级写操作 |
| 审批 | 系统保留的可信头部、动作范围、期限、拒绝/转HC | 高风险、截断信息、身份不足一律不能批准 |
| 故障 | 已离线/待确认/结果不确定/权限撤回 | 不以绿色成功状态隐藏 UNKNOWN |

## 7. 完成标准

模拟器、Web Provider 和 Mosaico 对相同 `display.card.v1` 合约给出一致结果。一个真实 Runtime 必须经 MCP 触发这条链路。危险动作的重放、设备失联、浏览器挂起、权限过期和取消竞争均有可理解的界面状态。

首版只承诺配对、通知卡、状态、受限交互、撤销和明确失败。按键语音与审批是随后独立切片；电机/继电器、后台手机自动拍摄、任意电脑操作、Linux 板端运行和自动资源调度不在首版范围。
