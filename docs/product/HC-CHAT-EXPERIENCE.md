# HC Web：以对话为中心的交互

- 日期：2026-09-13
- 范围：继续 `design/device-fabric-foundation`；只调整 HC Web 和对应测试，不实现 Device Fabric。
- 代码起点：`2bf874155f08d59a2429fcfeeff9984d965e1e2a`。

## 产品决策

采用常见聊天产品的布局：左侧新建/搜索/本页会话，中间消息，底部输入框；空白页提供输入与三个可编辑起始建议。连接、密钥指纹、注册和诊断收进设置弹窗/执行环境面板，不再占据首页。

保留 Harness 自身身份，不复制第三方品牌、商标或暗示与其服务连接。Agent 来自用户的本地 Runtime 配置，不虚构模型下拉选项。

## 已编写的交互合同

- 首次发送前连接账户和执行环境，草稿保留；连接完成仍由用户明确发送。
- 首条消息创建会话，密钥与ACTIVE状态就绪后发送该次明确请求。重复点击和未完成轮次禁止再次发送。
- 匹配原请求ID的响应完成一轮；文本chunk合并到同一助手消息。不把thought/tool/协议JSON当普通回答，也不插入“turn completed”系统噪声。
- Enter发送，Shift+Enter换行；composition状态、229键码和compositionend后的短保护窗口避免中文输入法误发送。
- 安全Markdown子集：段落、标题、列表、引用、行内代码、围栏代码、显式HTTP(S)/mailto链接。无raw HTML、外部图片、脚本或动态执行；并非完整CommonMark实现。
- 复制代码/回复由用户点击触发；剪贴板失败有提示。
- 查看旧消息时不强制滚到底部，提供“回到最新”。手机侧栏抽屉、独立滚动、动态viewport和safe-area适配。
- 设置弹窗关闭不卸载连接组件；网络断开不卸载Session或丢失本页密钥。重新连接只走原AWP Resume，不自动重发Prompt。
- 新建对话若需要结束活动会话，先明确确认，再等待执行端终态；没有终态就不开始新会话。
- 方形按钮叫“结束当前会话”，映射现有CloseTunnel路径，不冒充尚未实现的细粒度停止生成/ACP cancel，也不宣称撤销已发生操作。

## 历史与隐私边界

当前后端未提供完整的跨刷新会话密钥恢复和可读历史服务。本页保留至多20份只读记录并限制总显示字符数，不把聊天、标题或Token写入Local Storage。刷新后只列出可由现有API发现的待处理旧会话，不伪造可继续历史。当前仍只有一个活动加密会话；旧记录不可编辑/重新生成。

大于显示预算的回复有明确截断说明。完整原Frame仍由现有inbox路径处理；本轮不改变crypto、AAD、签名和认证API。
