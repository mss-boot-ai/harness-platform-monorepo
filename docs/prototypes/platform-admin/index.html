3. 五态

ReadyEmptyLoadingError403 Forbidden

Ready

正常渲染数据表，页脚展示总数与分页；写操作按钮按权限出现。

Empty

暂无 Endpoint。
先在本地启动 ABA 并完成设备授权。

Loading

骨架占位，表格列头先出现，避免页面跳动。不显示不确定的计数为 0。

Error

加载失败无法读取 Endpoint 列表。请重试；若持续失败请联系管理员并附上请求 ID。

只展示稳定错误码与下一步动作，不展示堆栈、SQL 或内部路径。

403 Forbidden

无权限当前账号缺少 harness:operate，无法执行该操作。请联系管理员分配角色。

403 是正常兜底：即使前端渲染了控件，后端也必须拒绝。

4. 权限矩阵

权限允许页面落点
harness:read只读查看五类列表与详情Overview、Sessions
harness:operate日常操作：审批外的投递暂停/恢复等Delivery
harness:approve批准 Enrollment 等敏感变更Enrollments
harness:revoke吊销 Endpoint / CredentialEndpoints

权限通过 Migration、路由绑定和拒绝测试落地。原型只表达绑定关系，新增权限必须同步更新正式文档与测试。
