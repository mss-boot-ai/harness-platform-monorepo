Platform 管理后台还原稿

Platform（mss-boot-admin v1.3.7 Thin Host）Harness 业务页面的静态还原。本稿的关键改进：**应用外壳不再是重建，而是从 @mss-boot-io/admin-web 1.3.7 的包内源码取得实数** —— 默认主题、布局模式、品牌、圆角、按钮高度、Foundation 全部菜单名、水印与页脚全部对齐。

v0.3 F4 还原稿 外壳：包内源码级 使用者：管理员 + 运维 10 屏 antd 6.6.1 · admin-web 1.3.7

v0.2 → v0.3 的重要更正：默认主题是暗色。default-settings.ts 里 navTheme: 'realDark'，而 theme.ts 用 navTheme === 'realDark' ? theme.darkAlgorithm : theme.defaultAlgorithm 驱动 antd，ThemeRuntimeProvider 再把它交给 ConfigProvider，同时设置 html.colorScheme='dark'。所以整个后台默认是暗色的。v0.2 按浅色重建，方向就是错的。

另一处更正：Foundation 菜单是可读的。此前以为它在运行时注入、读不到；实际 package/core-routes.cjs 列出了全部核心路由，package/locales/zh-CN.ts 给出中文名。因此侧栏现在是完整 17 项，不是 1 项。

仍非逐像素：ProLayout 内部配色、antd 组件的像素级间距与动效、菜单图标 path（@ant-design/icons 未安装）、品牌 logo 图形（第三方商标，不复制）。详见第 3 节。

3. 还原偏差（必须知道）

1. 品牌 logo 用占位块代替。生产用 /logo.svg（166×166 的内嵌位图，mss-boot-io 商标）。按项目约定「不复制第三方品牌、商标」，本稿只还原 28×28 的尺寸与位置，图形用占位块。
2. 菜单图标 path 为近似。@ant-design/icons 未安装。图标语义取自 core-routes.cjs 的 icon 字段（dashboard / user / team / menu / apartment / cluster / wallet / message / fileText / inbox / setting / translation / unorderedList / layout / safety / desktop），图形为自绘近似。
3. ProLayout 内部配色为按 realDark 语义重建。顶栏与侧栏用 #001529、选中项用 colorPrimary。ProLayout 的实际 token 值（尤其悬停态与子菜单缩进）可能略有差异。
4. antd 暗色 token 取 antd 6 darkAlgorithm 默认值（bg-layout #000、bg-container #141414、bg-elevated #1f1f1f、border #424242、text rgba(255,255,255,.85)），非从构建产物 CSS 读取。已确认的实数只有：borderRadius 8、Button.controlHeight 36、Card.headerFontSize 16、Table.headerBg = colorFillQuaternary、cssVar.prefix = mss、字体栈以 Inter 开头。
5. 示例数据为占位值。端点名、ID、时间、Runtime / Workspace、字节数均为按源码字段格式编造；ID 截断形式匹配 CompactID 的 ellipsis（maxWidth:180）。
6. 交互未绑定。Tabs、按钮、链接、Popconfirm、Modal 均为静态展示，不响应点击；水印为静态平铺，不随登录用户变化。
7. 未覆盖。真实登录跳转（/user/login，layout:false）、菜单搜索浮层、通知浮层、语言切换浮层、头像下拉菜单、message.useMessage() 全局提示、colorWeak 的 body{filter:invert(80%)}、移动端 AccessibleMobileHeader、面包屑的完整层级、表头排序与列宽拖拽。
