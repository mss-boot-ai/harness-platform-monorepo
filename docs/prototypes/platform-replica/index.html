Platform 管理后台还原稿

Harness 业务五个页面的静态还原。页面标题、描述、表格列、操作按钮、状态标签配色与弹窗文案全部取自本仓库源码（见文件头注释列出的路径），不是重新设计。

v0.1 F4 还原稿 外壳为重建 使用者：管理员 + 运维 7 屏 antd 6.6.1

还原范围的关键限制：左侧导航、顶栏、布局与主题 token 由 @mss-boot-io/admin-web 1.3.7 提供。该包不在本仓库，本地也未安装依赖，无法逐字读取其实包源码或编译产物 CSS，因此这部分按 antd 6.6.1 默认设计变量与 ProLayout 常见形态重建，不是逐像素取自实包。页面主体（标题/描述/Tabs/表格/按钮/弹窗）来自仓库源码，可信度更高。若要消除这一差距，需要在该目录执行依赖安装后重新对照。

3. 还原偏差（必须知道）

1. 应用外壳未逐像素还原。左侧导航、顶栏、布局、主题 token、PageContainer / PageEmpty / PageError / PageLoading / PageForbidden 的具体外观都来自 @mss-boot-io/admin-web 1.3.7。该包不在仓库内，本机也没有安装依赖，因此无法读取其实包源码或构建产物 CSS。本稿按 antd 6.6.1 默认设计变量重建，侧栏宽度、品牌区、菜单字体、空态插画等细节可能与生产界面不同。
2. Foundation 菜单未还原。platform/web/src/generated/routes.ts 是空数组，Foundation 菜单由运行时包注入。因此侧栏只画了源码可确认的一条「Harness 平台」，其余位置用虚线框说明原因，没有虚构菜单名。
3. 示例数据为占位值。端点名、ID、时间、Runtime / Workspace、字节数均为按源码字段格式编造的示例，不是任何真实运行数据。文中 ID 已被截断成 … 形式以匹配 CompactID 的 ellipsis 行为。
4. 标签色是映射表还原。颜色取自 harness/format.tsx 的 statusColors 表（ACTIVE→green、APPROVED→blue、PENDING→gold、SUSPENDED/REKEY_REQUIRED→orange、DENIED/FAILED/REVOKED/CONFLICT→red、UNCERTAIN→volcano、CLOSED→default）。antd 各色的实际色值按 antd 6 默认调色板重建，不是取实包 CSS。
5. 交互未绑定。按钮、链接、Tabs、弹窗均为静态展示；Popconfirm 与 Modal 用叠加层复现视觉，不响应点击。
6. 未覆盖。真实登录跳转、请求头与 CSRF、Idempotency-Key 生成过程、message.useMessage() 的全局提示动效、i18n 切换（en-US）、表头排序与列宽拖拽、响应式断点下的真实折叠行为。
