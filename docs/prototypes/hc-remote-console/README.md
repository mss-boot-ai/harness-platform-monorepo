# HC 远程会话主界面

- 版本：v0.1
- 状态：Partial impl
- 界面：HC（Web / PWA）中以对话为中心的远程会话主界面，含会话列表、消息区、权限卡、输入区与连接/执行状态。
- 使用者：最终用户
- 关联文档：[`../../remote/README.md`](../../remote/README.md) §9、[`../../product/HC-CHAT-EXPERIENCE.md`](../../product/HC-CHAT-EXPERIENCE.md)、[`../../architecture/HC.md`](../../architecture/HC.md) §13/§16/§19/§21、ADR-0005
- 关联代码：`hc/web/src/chat`、`hc/web/src/remote`、`hc/packages/core`
- 已实现部分：生产 HC 应用已接入持久会话控制器；同一浏览器端点范围的刷新恢复、双会话配置/草稿/事件隔离、标签页独占与接管、审批/取消后继续、原始密文补传、吊销拒绝。证据见 [`../../roadmap/verification/2026-09-14-hc-remote-conversations.md`](../../roadmap/verification/2026-09-14-hc-remote-conversations.md)。
- 未实现部分：跨设备 Attachment 独立授权与控制租约；执行主机/工作区写入隔离与 Host 重启恢复；真实模型端到端验收；资源与成果视图、PWA 通知；320/390px 之外的移动端真机验证。
- 非目标：不是像素稿；不定义新的协议字段、状态或 API 路径；不替代 `docs/remote/` 的产品范围定义。
- 首次建立：2026-09-15
- 最后更新：2026-09-15

## 1. 界面目标

用户不需要先填写 Task/Run 表单。入口就是「新建对话 + 输入框」，底层对象自动建立，复杂元数据收进详情与设置。原型要确认的是：

- 会话列表、消息流、输入区三段的层级是否清晰；
- 同一屏内如何同时看到**连接状态**与**执行状态**；
- 权限请求是否在不中断阅读的前提下足够显眼；
- 安全提示（Opaque、UNCERTAIN、Backpressure）放在哪一层。

## 2. 布局与信息层级

```text
桌面：左侧会话列表（新建/搜索/本页会话） · 中间消息区 · 底部输入区
移动：顶部标题与端点 · 消息区 · 底部输入区；侧栏收进抽屉
设置：连接、密钥指纹、注册、诊断、端点管理全部收进设置弹窗/执行环境面板，不占首页
```

- 连接与密钥信息**不进首页**（`HC-CHAT-EXPERIENCE.md` 产品决策）。
- 不虚构模型下拉选项；Agent 能力来自用户本地 Runtime 配置。
- 不复制第三方品牌、商标，也不暗示与其服务连接。

## 3. 关键状态与流转

### 3.1 输入区状态（原型 §3 已逐项画出）

| 状态 | 文案要点 | 约束 |
| --- | --- | --- |
| 未发送草稿 | 「尚未发送」 | 按会话隔离；刷新后按会话恢复 |
| 发送未确认 | 「已提交，等待执行端确认」 | 重复点击禁用；网络恢复不自动重发 |
| 执行中 | 「本轮执行中，可请求取消」 | 取消只发送一次 |
| 取消待确认 | 「取消请求已发出，等待终态」 | 无终态前不开始新轮 |
| 可继续 | 正常可输入 | — |
| 连接断开 | 「草稿保留，连接恢复后再发送」 | Session 不卸载；只走 Resume |

### 3.2 两类状态必须分开（原型 §4）

| 维度 | 取值 | 展示位置 |
| --- | --- | --- |
| 连接状态 | 正常 / 重连中 / 积压 / 已吊销 | 顶部状态栏 |
| 执行状态 | 空闲 / 执行中 / 等待审批 / 取消待确认 / 结果不确定 / 已失败 | 会话内条目与输入区 |

组合必须分别可见，例如「重连中 + 上一轮执行中」。不能用连接绿灯掩盖执行端的 `UNCERTAIN`。

## 4. 安全相关表达

- **Opaque 提示**：会话内固定一条信息条——「会话内容在此 HC 与 ABA 之间加密。Platform 可见连接、时间、大小和路由元数据。」
- **`UNCERTAIN` 置顶**：位于消息区首条，文案明确「结果无法确认，不自动重试」，并要求用户选择（检查工作区 / 结束会话）。
- **权限卡**：展示来源 ABA、Session/Workspace 展示名、工具类型、目标摘要、风险等级、允许范围与有效期；提供「拒绝 / 仅本次允许 / 本 Session 允许」，**不提供**「永久允许所有命令」。原型已注明 ABA 本地硬策略优先于 HC 允许。
- **Backpressure**：显示为独立提示条，明确「未确认内容不会静默丢弃」，不做静默排队。
- **结束当前会话**：方形按钮映射现有 CloseTunnel 路径，原型显式标注它**不**冒充细粒度停止生成，也不宣称撤销已发生的操作。
- **usage**：无准确 token 数据时显示 unknown，不按字符数推算。
- **Assurance**：设置面板展示 `web-software`，不把浏览器软件密钥宣传成硬件级安全。
