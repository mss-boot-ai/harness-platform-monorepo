2. 画面

3. 还原偏差（必须知道）

1. 画廊外壳。为在同一文件里并排展示 10 屏，额外加了 .gal / .screen 两组样式，并把 .chat-shell 的 height:100dvh 覆盖为 100%。生产界面里没有这两组样式。
2. 弹窗背景。生产代码用 <dialog> 的 ::backdrop；静态文件无法调用 showModal()，因此用一层 .dialog-stage 复现同一视觉（#10181350 + blur(3px)）。<dialog open> 本身不是模态。
3. 示例数据。会话标题、Runtime ID、指纹、时间、工具输入输出全部为占位值，取自源码里的字段名与格式规则，不是任何真实运行数据。
4. 交互。静态页面里的按钮不绑定行为；<details> 折叠可以展开，输入框可输入但不发送。
5. 未覆盖。PWA 安装提示、manifest.webmanifest、跳过链接的实际焦点跳转、中文输入法 composition 保护、WebSocket 真实连接过程、IndexedDB 实际读写。
