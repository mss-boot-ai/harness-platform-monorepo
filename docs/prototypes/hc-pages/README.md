## 2. 关键状态与流转

### 2.1 输入区六态（C3/C4）

未发送草稿 → 发送未确认 → 执行中（可取消）→ 取消待确认 → 可继续；另有连接断开态。必须区分「用户是否已明确发送」与「执行端是否已确认」，不得用一个「发送中」笼统表达。

### 2.2 连接状态机（B3）

```text
SIGNED_OUT → HUMAN_AUTHENTICATED → ENDPOINT_READY → TICKET_ISSUING
→ CONNECTING → CHALLENGED → READY → RECONNECTING → REVOKED/CLOSED
```

### 2.3 两类状态必须分开

| 维度 | 取值 | 展示位置 |
| --- | --- | --- |
| 连接状态 | 正常 / 重连中 / 积压 / 已吊销 | 顶部状态栏 |
| 执行状态 | 空闲 / 执行中 / 等待审批 / 取消待确认 / 结果不确定 / 已失败 | 会话内条目与输入区 |

组合必须分别可见，例如「重连中 + 上一轮执行中」。不能用连接绿灯掩盖执行端的 `UNCERTAIN`。

## 3. 安全相关表达

- **Opaque 提示条**：会话内容在 HC 与 ABA 之间加密；Platform 可见连接、时间、大小与路由元数据。
- **`UNCERTAIN` 置顶**：明确「结果无法确认，不自动重试」，要求用户检查工作区或结束会话。
- **权限卡**：来源、Session / Workspace、工具类型、目标摘要、风险等级、允许范围与期限；三个按钮，无「永久允许所有命令」；ABA 本地硬策略优先。
- **Backpressure**：独立提示条，不静默排队；未确认内容不静默丢弃。
- **吊销**：停止连接、清除可撤销凭据、不自动重新注册。
- **Managed Mode**：必须写明「Platform 可以读取内容」，需二次认证，不使用绿色端到端加密标识。
- **Assurance 诚实**：`web-software` 不得宣传为硬件级安全。
- **usage**：无准确 token 数据时显示 unknown，不按字符数推算。
