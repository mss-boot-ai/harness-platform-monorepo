HC 远程会话主界面

用户在手机或桌面浏览器中查看会话、发送输入、处理权限请求并观察执行与连接状态。本原型为低保真线框，用于确认信息层级与状态表达，不是像素稿。

v0.1 Partial impl 使用者：最终用户 关联代码：hc/web/src/{chat,remote}

4. 执行状态与连接状态分开展示

维度取值展示位置
连接状态正常 · 重连中 · 积压 · 已吊销顶部状态栏
执行状态空闲 · 执行中 · 等待审批 · 取消待确认 · 结果不确定 · 已失败会话内条目与输入区

两者组合必须分别可见：例如「连接重连中 + 上一轮执行中」。不能用一个绿灯掩盖执行端的 UNCERTAIN。
