1. 复制整个目录并重命名（kebab-case，描述界面，例如 `session-permissions/`）。
2. 改 `index.html` 的 `<title>`、`h1`、版本徽标 `v0.1`、状态徽标与内容；**保留顶部样式块**，它是规范样式源。
3. 用下方骨架重写本 README，其中「版本」填 `v0.1`，并建立版本记录表。
4. 在 `docs/prototypes/README.md` §3「原型清单」新增一行，版本列填 `v0.1`。
5. 按 `AGENT.md` §6：先 commit + push，再做检查。

## 硬约束

- 自包含单文件 HTML，禁止外部 CDN、脚本、字体、图片。
- 不得出现真实密钥、Token、Ticket、生产地址或用户数据。
- 不得把未实现能力表达为已完成。
- 版本号必须同时出现在 README 头部、`index.html` 徽标、总清单三处且一致。
