# 2026-09-04 MVP 范围记忆

## 当前目标

在 `codex/bootstrap-harness-platform-foundation` 完成一个真实、单实例、默认 Opaque 的 Harness Platform MVP，并在完整验证后向 `main` 创建 PR，不自动合并。

## 必须形成的闭环

```text
ABA Enrollment
→ Human Approval
→ HC Registration
→ DPoP + Ticket + WSS Challenge
→ Session + local allowlist
→ HPKE Key Package
→ encrypted ACP request/response
→ ACK + reconnect replay
→ endpoint revocation
→ opaque canary zero hit
```

## 实现边界

- Platform 是 mss-boot-admin v1.3.7 Thin Host；
- Admin Server 处理 Human 管理面；
- 独立 Gateway 处理 Endpoint HTTP/WSS；
- ABA 使用 Rust；
- HC 使用 TypeScript/WebCrypto，并提供 Node E2E Runner；
- Test ACP Agent 只用于确定性 MVP 验证；
- 单用户、单 ABA、单 HC、单 Session 是本轮产品范围，不得由此降低独立密钥、加密、可靠性或吊销要求。

## 交付纪律

每个检查点先 push，再测试。测试失败的修复必须形成新 push 后才重测。最终 PR 只在版本化验证报告和最终 CI 通过后创建。
